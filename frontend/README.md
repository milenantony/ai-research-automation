# PaperX frontend

React and Vite frontend for AI Research Automation.

## Development

Start the FastAPI backend at `http://127.0.0.1:8000`, then run:

```cmd
npm install
npm run dev
```

Open `http://localhost:5173/`. Vite proxies `/research-jobs` requests to the backend.

## Checks

```cmd
npm run lint
npm run build
```
